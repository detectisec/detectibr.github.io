DetecTI-CLI Community Edition

Engine moderna de Alta Performance, Assíncrona e Modular para External Attack Surface Management (EASM), Reconhecimento de Ativos e Inteligência de Armamento de Vulnerabilidades.

Python 3.11+ Asyncio / HTTPX SQLite EASM Cytoscape.js MIT License

1. Introdução

O DetecTI-CLI foi projetado e construído pela DetecTI Security para solucionar um dos maiores desafios de equipes ofensivas (Red Teams, Pentesters) e defensivas (SOC, Threat Hunters, Blue Teams): a visibilidade fragmentada e a sobrecarga de ruído na superfície de ataque externa exposta à Internet.

Em vez de executar ferramentas isoladas e lidar com dados desconexos em CSVs, o DetecTI-CLI opera como um pipeline de orquestração unificado. Ele descobre a infraestrutura conectada, correlaciona relações organizacionais via Reverse WHOIS e Certificate Transparency, mapeia portas/serviços ativos e enriquece automaticamente cada vulnerabilidade detectada com métricas de probabilidade de exploração no mundo real (FIRST EPSS), catalogação de exploração ativa em ransomware (CISA KEV), taxonomia de fraquezas (CWE) e provas públicas de conceito (ExploitDB + GitHub PoCs).

Filosofia BloodHound-like para EASM

Assim como o BloodHound revolucionou a análise de caminhos de ataque no Active Directory modelando permissões em grafos, o DetecTI-CLI modela a superfície de ataque externa como um grafo de relacionamentos orientados (Target Root → Domains → IPs → Services → CVEs → PoCs).

Mapeamento EASM Concorrente

Execução ultra rápida assíncrona para IP único, blocos CIDR (/24), domínios, emails, CVEs e buscas complexas do Shodan/Censys.

Priorização por Risco Real

Elimine a fadiga de alertas: priorize ativos através do cruzamento entre CVSS Base, FIRST EPSS (probabilidade) e CISA KEV (exploração ativa).

Dashboard Gráfico Interativo

DetecTI Hound WebGUI embarcado em FastAPI + Cytoscape.js para exploração visual de nós, inspeção técnica e filtros instantâneos.

3. Guia de Instalação (Quickstart)

O DetecTI-CLI suporta execução nativa em Linux, macOS e Windows (via WSL2). Siga os passos abaixo para preparar o ambiente:

Pré-requisitos de Sistema

Requer Python 3.11 ou superior e o gerenciador de pacotes pip ou ambiente virtual venv.

Passo 1: Clonar e Instalar Dependências

Bash 
# Clonar o repositório oficial
git clone https://github.com/detectisec/DetecTI-CLI.git
cd DetecTI-CLI

# Criar e ativar o ambiente virtual (Recomendado)
python3 -m venv detecti-venv
source detecti-venv/bin/activate

# Instalar em modo editável ou via requirements
pip install -e .

# Conceder permissão de execução ao binário
chmod +x detecti-cli

Passo 2: Inicializar o Banco de Exploits (ExploitDB)

O DetecTI-CLI possui um módulo integrado de busca local de exploits (searchsploit). Execute a atualização inicial do catálogo:

Bash 
./detecti-cli update-xdb

4. Configuração de Chaves & APIs

O DetecTI-CLI foi construído com design tolerante a falhas. Caso nenhuma chave seja fornecida, a ferramenta utiliza automaticamente fontes e fallbacks públicos gratuitos (crt.sh, HackerTarget, FIRST EPSS API, CISA KEV Catalog e GitHub PoC API). No entanto, para capacidade de varredura profunda de infraestrutura e bypass de rate-limits, recomendamos a configuração de variáveis de ambiente.

Crie um arquivo .env na raiz do projeto ou configure em seu shell (~/.bashrc / ~/.zshrc):

.env 
# [Recomendado] Shodan API Key (Essencial para queries e varreduras de IP/Banner)
SHODAN_API_KEY="seu_shodan_api_key_aqui"

# [Opcional] Censys Platform API v3 PAT Token e Org ID
CENSYS_PAT_TOKEN="seu_censys_pat_token_aqui"
CENSYS_ORG_ID="seu_censys_org_id_aqui"

# [Opcional] NVD API Key (Acelera requisições de CVSS/CWE sem rate-limit)
NVD_API_KEY="sua_nvd_api_key_aqui"

# [Opcional] WhoisFreaks API Key (Reverse WHOIS de alta precisão)
WHOISFREAKS_API_KEY="sua_whoisfreaks_api_key_aqui"

# [Opcional] GitHub Token (Para consultas de PoCs de exploits sem limite de requisição)
GITHUB_TOKEN="seu_github_personal_token_aqui"

Verificando a Configuração

Bash 
./detecti-cli config-check

5. CLI Operation & Varreduras

A interface de linha de comando é gerenciada via Typer e estilizada com Rich, fornecendo formatação limpa, indicadores de progresso assíncronos e tabelas de risco coloridas.

Modos de Varredura por Alvo

Tipo de Alvo Exemplo de Comando Ações Executadas no Pipeline
Domínio Raiz ./detecti-cli scan -t spacex.com Enumeração crt.sh + Reverse WHOIS + Resolução DNS + Shodan/Censys + CVE Scoring
Endereço IP Único ./detecti-cli scan -t 142.250.191.68 Perfil Shodan + Censys v3 Dossier + Portas + Serviços + Banner Analysis + CVEs
Sub-rede CIDR ./detecti-cli scan -t 142.250.191.0/24 Varredura de bloco de rede + Enumeração de hosts ativos + Correlação de portas
CVE Identifier ./detecti-cli scan -t CVE-2021-44228 NVD CVSS v3.1 + CWE + Probabilidade FIRST EPSS + Flag CISA KEV + ExploitDB + PoCs
Shodan Dork / Query ./detecti-cli scan -t "org:'Acme Corp' port:443" Busca de infraestrutura customizada, extração de certificados e correlação de vulnerabilidades

Flags Principais & Módulos

Flag Valores Permitidos Descrição Técnica
-t, --target STRING Alvo da análise (IP, Domínio, CIDR, CVE, Shodan Dork ou file:targets.txt).
-m, --modules all, shodan, censys, crtsh, reverse_whois, nvd, exploitdb Lista separada por vírgulas dos coletores específicos a habilitar.
--cvss critical, high, medium, low Filtra vulnerabilidades exibidas e exportadas por severidade mínima.
--create-db NOME_DO_BANCO Salva os dados automaticamente em ./data/dbs/{nome}.sqlite para o WebGUI.
-o, --format table, json, markdown, html, all Formato de saída do relatório de segurança.
-f, --output-file PATH Caminho customizado de destino do arquivo exportado.
-d, --output-dir DIRECTORY Diretório de destino para exportação de múltiplos formatos (quando -o all).

Persistência Centralizada SQLite (EASM)

Para persistir os dados para consulta histórica ou carregar no DetecTI Hound Web Dashboard, utilize a flag --create-db:

Bash 
# Mapeia empresa e salva em ./data/dbs/alvo_empresa.sqlite
./detecti-cli scan -t empresa.com.br --create-db alvo_empresa

# Mapeia sub-rede e salva em ./data/dbs/datacenter_sp.sqlite
./detecti-cli scan -t 198.51.100.0/24 --create-db datacenter_sp

Exportação de Relatórios Oficiais

Exemplos de Exportação 
# 1. Relatório Executivo em Markdown
./detecti-cli scan -t empresa.com.br -o markdown -f relatorio_executivo.md

# 2. Relatório HTML Standalone (Formatado e Pronto para Print/PDF)
./detecti-cli scan -t empresa.com.br -o html -f relatorio_easm.html

# 3. Dados Estruturados em JSON para SIEM/SOAR/Data Lake
./detecti-cli scan -t empresa.com.br -o json -f surface_data.json

# 4. Exportação simultânea de todos os formatos para pasta
./detecti-cli scan -t empresa.com.br -o all -d ./exports/empresa/

6. WebGUI: DetecTI Hound Dashboard

O DetecTI Hound é a interface gráfica web interativa inspirada na experiência analítica de grafos do SpecterOps BloodHound. Ele opera através de um servidor FastAPI de alta performance que lê os bancos de dados SQLite gerados e renderiza o grafo interativo utilizando Cytoscape.js.

Gerenciamento do Servidor Hound (Daemon)

O gerenciamento do ciclo de vida do servidor web é realizado através do subcomando hound:

Comando Função Técnica
./detecti-cli hound start Inicia o servidor FastAPI em segundo plano na porta 8000 (http://127.0.0.1:8000).
./detecti-cli hound list-dbs Lista todos os bancos de dados de superfícies de ataque salvos em ./data/dbs/.
./detecti-cli hound status Verifica o status do processo daemon (PID, porta, consumo e tempo de atividade).
./detecti-cli hound stop Finaliza com segurança o processo daemon em execução.
Iniciar o Hound WebGUI 
# Iniciar a interface gráfica
./detecti-cli hound start

# Acesse no navegador:
# http://127.0.0.1:8000

Controles, Layouts e Filtros de Risco

  • Seletor Dinâmico de Bancos: Alterne entre qualquer base de dados SQLite em ./data/dbs/ diretamente pelo menu superior sem reiniciar o servidor.
  • Algoritmos de Layout: Alterne com 1 clique entre ⚡ Force-Directed (Cose-Bilkent), 🌳 Hierárquico Top-Down (Dagre), 🎯 Concêntrico e ▦ Grade.
  • Filtros Rápidos de Risco:
    • Apenas CISA KEV: Exibe exclusivamente ativos com vulnerabilidades exploradas ativamente por agentes de ameaça/ransomware.
    • Alto EPSS (> 50%): Destaca falhas com probabilidade matemática iminente de exploração.
    • Com Exploit/PoC Público: Filtra vulnerabilidades que possuem scripts no ExploitDB ou repositórios no GitHub.
    • Isolamento de Lead: Selecione um host específico para focar sua subárvore e ocultar ruídos laterais.

Asset Inspector Lateral

Ao clicar com o botão esquerdo em qualquer nó do grafo, a gaveta do Asset Inspector se abre exibindo metadados técnicos aprofundados: vetores CVSS v3.1, fraqueza CWE associada, porcentagem e percentil FIRST EPSS, presença no catálogo CISA KEV, banner do serviço e links diretos para os exploits verificados.

7. Threat Intelligence & Matriz de Priorização

O modelo tradicional de priorização baseado puramente em notas CVSS estáticas está obsoleto. Uma vulnerabilidade CVSS 9.8 sem exploit conhecido representa menos risco operacional imediato do que uma falha CVSS 7.5 amplamente explorada por operadores de ransomware.

O DetecTI-CLI implementa a Matriz Tridimensional de Risco EASM:

1. CISA KEV (Known Exploited)

Catálogo da Agência de Cibersegurança dos EUA de vulnerabilidades confirmadas como armas em ataques reais. Flag máxima de prioridade (P1).

2. FIRST EPSS Probability

Modelo preditivo de Machine Learning da FIRST que estima a probabilidade de exploração ativa nos próximos 30 dias (0.0% a 100.0%).

3. PoC Weaponization Index

Cruzamento em tempo real com arquivos locais do ExploitDB e repositórios públicos do GitHub contendo código funcional de exploração.
