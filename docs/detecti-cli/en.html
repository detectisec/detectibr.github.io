DetecTI-CLI Community Edition

Modern High-Performance, Asynchronous & Modular Engine for External Attack Surface Management (EASM), Asset Reconnaissance, and Vulnerability Weaponization Intelligence.

Python 3.11+ Asyncio / HTTPX SQLite EASM Cytoscape.js MIT License

1. Introduction

DetecTI-CLI was engineered by DetecTI Security to solve one of the greatest challenges faced by offensive teams (Red Teams, Pentesters) and defensive operations (SOC, Threat Hunters, Blue Teams): fragmented visibility and alert fatigue across the external internet-facing attack surface.

Instead of running isolated tools and stitching together disconnected CSVs, DetecTI-CLI executes as a unified orchestration pipeline. It discovers exposed internet assets, correlates organizational relationships via Reverse WHOIS and Certificate Transparency, maps active services, and automatically enriches every vulnerability with real-world exploitation risk (FIRST EPSS), active exploitation & ransomware tracking (CISA KEV), weakness classification (CWE), and public weaponization proofs (ExploitDB + GitHub PoCs).

BloodHound Philosophy for EASM

Just as BloodHound transformed Active Directory attack path analysis by modeling permissions as graphs, DetecTI-CLI models the external attack surface as an interconnected, query-anchored graph (Target Root → Domains → IPs → Services → CVEs → PoCs).

High-Concurrency EASM

Ultra-fast asynchronous scans for single IPs, CIDR ranges (/24), root domains, emails, CVE IDs, and complex Shodan/Censys queries.

Real-World Risk Prioritization

Eliminate alert fatigue: prioritize critical exposures by crossing CVSS Base with FIRST EPSS probability and CISA KEV exploitation flags.

Interactive Attack Surface Graph

Built-in DetecTI Hound WebGUI powered by FastAPI + Cytoscape.js for intuitive node inspection, area selection, and scoped lead filtering.

3. Installation Guide (Quickstart)

DetecTI-CLI runs natively across Linux, macOS, and Windows (via WSL2).

System Requirements

Requires Python 3.11 or higher and pip / venv virtual environment manager.

Step 1: Clone and Install Dependencies

Bash 
# Clone repository
git clone https://github.com/detectisec/DetecTI-CLI.git
cd DetecTI-CLI

# Create and activate virtual environment
python3 -m venv detecti-venv
source detecti-venv/bin/activate

# Install in editable mode
pip install -e .

# Grant executable permission
chmod +x detecti-cli

Step 2: Initialize Exploit Database (ExploitDB)

Bash 
./detecti-cli update-xdb

4. Configuration & API Keys

DetecTI-CLI includes free out-of-the-box fallbacks (crt.sh, HackerTarget, FIRST EPSS, CISA KEV, and GitHub PoC API). To unlock deeper network range profiling, configure your API keys in .env:

.env 
# [Recommended] Shodan API Key
SHODAN_API_KEY="your_shodan_api_key_here"

# [Optional] Censys Platform API v3 PAT Token and Org ID
CENSYS_PAT_TOKEN="your_censys_pat_token_here"
CENSYS_ORG_ID="your_censys_org_id_here"

# [Optional] NVD API Key (Accelerates CVSS/CWE rate-limits)
NVD_API_KEY="your_nvd_api_key_here"

# [Optional] WhoisFreaks API Key (Structured Reverse WHOIS)
WHOISFREAKS_API_KEY="your_whoisfreaks_api_key_here"

# [Optional] GitHub Personal Access Token
GITHUB_TOKEN="your_github_token_here"

Verify Configuration

Bash 
./detecti-cli config-check

5. CLI Operation & Scans

Target Scan Modes

Target Type CLI Example Pipeline Action
Root Domain ./detecti-cli scan -t spacex.com crt.sh enum + Reverse WHOIS + DNS resolution + Shodan/Censys + CVE Scoring
Single IP Address ./detecti-cli scan -t 142.250.191.68 Shodan profile + Censys v3 dossier + Ports + Banners + CVEs
CIDR Subnet Range ./detecti-cli scan -t 142.250.191.0/24 Network block scan + Active host discovery + Port correlation
CVE Identifier ./detecti-cli scan -t CVE-2021-44228 NVD CVSS v3.1 + CWE + FIRST EPSS % + CISA KEV flag + ExploitDB + PoCs
Shodan Custom Query ./detecti-cli scan -t "org:'Acme Corp' port:443" Custom infrastructure asset discovery & vulnerability correlation

SQLite EASM Persistence

Bash 
# Scan domain and persist into ./data/dbs/company.sqlite
./detecti-cli scan -t company.com --create-db company

# Scan subnet and persist into ./data/dbs/datacenter.sqlite
./detecti-cli scan -t 198.51.100.0/24 --create-db datacenter

Executive Reports & Export

Export Examples 
# 1. Executive Markdown Report
./detecti-cli scan -t company.com -o markdown -f executive_report.md

# 2. Standalone Styled HTML Report (Print & PDF Ready)
./detecti-cli scan -t company.com -o html -f easm_report.html

# 3. Structured JSON for SIEM/SOAR integration
./detecti-cli scan -t company.com -o json -f attack_surface.json

# 4. Batch export of all formats into a directory
./detecti-cli scan -t company.com -o all -d ./exports/company/

6. WebGUI: DetecTI Hound Dashboard

DetecTI Hound provides an interactive graph visualization experience inspired by SpecterOps BloodHound, powered by FastAPI and Cytoscape.js.

Daemon Server Commands

Command Description
./detecti-cli hound start Starts background FastAPI server on port 8000 (http://127.0.0.1:8000).
./detecti-cli hound list-dbs Lists all saved SQLite attack surface databases in ./data/dbs/.
./detecti-cli hound status Checks daemon status (PID, port, uptime).
./detecti-cli hound stop Safely terminates background Hound server process.

Interactive Navigation, Controls & Context Menu

  • Left-Click (Drag): Continuous smooth panning across the attack surface graph.
  • Left-Click (Node): Single asset selection and opens the Lateral Asset Inspector.
  • Ctrl + Left-Click (or Cmd on macOS): Additive sequential multi-selection to select multiple target nodes simultaneously.
  • Right-Click (Node): Opens the Custom Context Menu with quick actions:
    • Collapse / Uncollapse Services: Group or expand services under the IP host.
    • Collapse / Uncollapse Vulnerabilities: Group or expand direct IP or service vulnerabilities.
    • Inspect Details: Open the detailed technical asset drawer.
    • Focus Node: Instantly zoom and center directly onto the target asset.
    • Copy Domain / Subdomain / IP / CVE: Copy the exact asset identifier to the clipboard.
  • Right-Click (Drag on Canvas): Box Area Selection to group and reposition blocks of nodes together.
  • Layout Algorithms:
    • Hierarchical Top-Down (Default): Structured top-down tree topology with compact adaptive spacing.
    • Force-Directed: Organic physics simulation with smooth spring transitions and calibrated repulsion.
    • Concentric & Grid: Concentric orbital rings and uniform asset matrices.
  • Quick Risk Filters:
    • CISA KEV Only: Restricts graph to active in-the-wild exploited vulnerabilities.
    • High EPSS (> 50%): Prioritizes imminent weaponization probabilities.
    • Public Exploits / PoCs: Filters for weaponized exploits in ExploitDB and GitHub.
    • Services Only / Vulnerable Services Only: Isolates active services layer and vulnerable hosts.
    • Search with Downstream Inheritance: Search by IP, domain, or port preserving ancestry to target root and child services/CVEs.

Lateral Asset Inspector

Left-clicking any node on the graph opens the Asset Inspector drawer displaying deep technical metadata: CVSS v3.1 vectors, associated CWE taxonomy, FIRST EPSS probability percentage and percentile, CISA KEV catalog status, service banners, and direct links to verified weaponization proofs.

7. Threat Intelligence & Risk Matrix

1. CISA KEV (Active Exploits)

Catalog of vulnerabilities actively leveraged in ransomware and targeted cyber campaigns (Priority 1).

2. FIRST EPSS Probability

Machine-learning predictive model estimating the probability of weaponization in the next 30 days.

3. Weaponization Index

Real-time cross-referencing against local ExploitDB archives and public GitHub proof-of-concept repositories.
